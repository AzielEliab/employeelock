EmployeeLock

Name the event. Name who owns the record. Chain the row.

This is a spreadsheet plus a checker. Each line asks what happened, what followed, who was named, what happened soon, what lasted, and who owns the record. Blank owner shows as UNOWNED. A moved name shows as RENAMED. We hash the line. We do not score truth.

THIS IS: workbook (COVER, LOG, EVIDENCE, CHAIN, OWNERS, DASH, LISTS) + CLI (init/append/import/verify) + linear hash chain + countermeasure against unowned/renamed rows. THIS IS NOT: UL or a BAL issue paper; FoldLock; TemporalLock (borrows ethic, different product); court filing / exhibit stickerer / counsel; truth score / consensus / token; remote uploader / anonymous relay; a charge sheet against a named living person. Demo rows are generic format proof, not case facts.
